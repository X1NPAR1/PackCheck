### New
- **Create wizard**: start from a profile (survival with friends, modded, creative build, minigames, hardcore, low-end PC), pick the platform from cards that explain each one, choose RAM with a 1–32 GB slider (with a warning when Windows would run short) and the number of CPU cores, set game mode, difficulty, players, view distance, PvP, whitelist, online mode, hardcore and MOTD. A free port is picked for you and a live summary estimates how many players the server handles.
- **Server page**: change memory, CPU cores and garbage-collector flags after creation; technical details with PID, threads, handles, private memory and the exact Java start command.
- **Delete server**: deletes the server folder from disk after two confirmations; PackCheck backups are kept.
- **Play over the internet**: step-by-step port forwarding guide with the exact values for your router, a button that opens the router page, and **Test from outside** to check that friends can really join. PackCheck offers to close open ports when you quit.
- **Tray menu**: themed menu with every server's live state, start/stop buttons, Validate, Settings and Stop all.
- **Console**: search highlights matches with next/previous (Enter / Shift+Enter), player names in the log are clickable (op, kick, ban, teleport), and the crash banner can hand the error to the assistant.
- **Plugins and Mods**: project details with the full description, category filter, and an **Update** button when a newer compatible file exists.
- **Validate**: group findings by severity, category or file, a tree of affected files, search, plugin inventory (version, API, size, SHA-256, dependencies), technical summary, and "Ask the assistant" on any problem.
- **Assistant**: xAI Grok, DeepSeek, Mistral and Groq added next to Claude, ChatGPT, Gemini, OpenRouter, Ollama and LM Studio. Models are picked from a list (suggested models right away, the full list after connecting). Answers stream in, are formatted, and every server keeps its own chat history.
- **Settings**: section sidebar and search. **About**: feature overview and system information you can copy for bug reports.
- **MSI**: optional "Start with Windows" feature.

### Fixed
- New Velocity and BungeeCord servers listened on 25577 instead of the chosen port.
- Two servers starting at the same time could break each other's Java download; Java is no longer re-downloaded over a runtime a running server uses.
- Console text in Turkish, Russian and other languages could show `?` instead of letters.
- Disabled Plugins/Mods menu items now tell screen readers why they are disabled.
- Settings sidebar text was hard to read in the dark theme.
