## PackCheck 3.3.0

### AI assistant
- **Finishes long jobs.** For tasks like "translate every plugin", the assistant first finds every message file. It then keeps a visible task list with one item per file and works through all of them. When it is done it shows a "Task complete" summary. If it stops while items are still open, PackCheck tells it to carry on. One message can now take up to 400 steps in Auto and Bypass, 120 in Normal and 40 in Plan; before 3.3.0 every mode stopped after 12.
- **Thinks between steps:** current Claude models (Opus, Sonnet and Fable 4.6 and newer) use adaptive thinking.
- **New tools:**
  - find files by pattern (`plugins/**/*.yml`);
  - search text across the server;
  - read large files in parts;
  - change an exact part of a file instead of rewriting it. Edits are backed up to `.packcheck/edits`.
- **Server picker** in the assistant, independent of the Servers page. Switching servers mid-chat is noted in the chat.
- **Chat history:** every conversation is saved. Open earlier chats, search titles and message text, or delete chats. History from older versions is moved over automatically.
- **Attachments:**
  - Screenshots and log or config files can be added with **+ File** (Ctrl+O), pasted with Ctrl+V, or dropped on the page.
  - Images are sent as pictures. This needs a model that can see images: Claude, GPT-4o/5, Gemini or Grok-4.
  - Text files are added to the message. Very long logs keep their last 120,000 characters.
- **Automatic retries:** busy or rate-limited providers (HTTP 429, 500, 502, 503, 504, 529) are retried automatically with growing waits. The status line shows when a retry happens.

### Keyboard and mouse
- **F11:** full screen over the whole monitor.
- **Alt+← / Alt+→ and the mouse back/forward buttons:** move through pages, servers and server tabs like a browser.
- **Middle click or Ctrl+W:** closes the open dialog, wizard or assistant history, or returns an open server tab to Overview.
- **Ctrl+Tab / Ctrl+Shift+Tab:** next / previous server tab.
- **Ctrl+1…9:** side-menu pages.
- **Ctrl+,:** opens settings.
- **F1:** lists all shortcuts.
- **In the assistant:** Ctrl+H opens history, Ctrl+N starts a new chat.

### Other
- The README shows the current version as text, and the download badge refreshes faster.
