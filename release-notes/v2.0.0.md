PackCheck now ships as a proper Windows installer (EXE and MSI). If you are on 1.x, the app updates itself to this version once and then moves to the installer-based updates.

### New
- **Installers**: per-user EXE and MSI setups, no admin rights needed. Start menu entry, optional desktop shortcut and "start with Windows". Updates install silently.
- **16 server platforms**: Paper, Purpur, Folia, Leaf, Leaves, Spigot and CraftBukkit (built with BuildTools), Vanilla, Fabric, Quilt, Forge, NeoForge, SpongeVanilla, and the hybrids Mohist, Youer and Arclight. Version lists come from each project, so only versions that can actually be downloaded are offered.
- **Automatic Java**: the Java version a server needs is installed (Eclipse Temurin) before it starts.
- **Live dashboard**: ring gauges for TPS, CPU, RAM and ping with five health levels, plus players, uptime, disk and world size.
- **New console**: log levels with filters and counters, search, timestamps, wrap, pause, copy and save, command history and completion, quick actions, player list and a crash banner.
- **Files tab**: browse the server folder, upload by drag and drop, multi-select, copy/cut/paste, zip/unzip, delete to the Recycle Bin, and a code editor with line numbers, syntax highlighting and a syntax check before saving.
- **server.properties editor**: every setting with a description, the right control for its type, defaults and reset.
- **Plugins and Mods pages**: browse Modrinth, Hangar and CurseForge page by page without searching. Items that do not fit the server's version or loader cannot be installed and explain why. Modpacks (Modrinth .mrpack and CurseForge server packs) are supported.
- **Online page**: open a server to the internet (firewall rule with your permission, UPnP on the router), copy the address, get A/SRV records for your own domain, optional DuckDNS. Close it again to go back to local only.
- **System tray**: closing the window keeps PackCheck and your servers running.

### Fixed
- Console lines were invisible in the light theme.
- Plugins and Mods entries in the sidebar now follow the selected server's platform.
- Newer Paper versions did not report TPS.
