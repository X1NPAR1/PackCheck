## PackCheck 4.0.0

A big update: a new look, a World tab, smarter content handling and server insights.

### New look
- **Pixel titles:** page titles and the logo use the Press Start 2P pixel font (OFL licence).
- **New icons:** every icon is now from the Lucide set (ISC licence), drawn with consistent strokes.
- **Servers in the sidebar:** each server's logo, name and a status dot; one click opens it.
- **Dashboard:** servers running, players online, memory given to running servers, crashes in the last 24 hours, and live TPS/CPU/RAM/players for every server.

### World tab
- **World controls:** set the time, weather and difficulty, switch 12 game rules on or off, and save the world, all with one click.
- **World library:**
  - Save a server's worlds, install a saved world on any server, import or export world zips, and delete saved worlds.
  - Installing keeps the current worlds in `old-worlds/`.
- **New world:** start over with a seed, or a random one.
- **Player inventory:** read any player's inventory, armour, off-hand and ender chest from their save file, including offline players. Health and level are shown too.
- **Live map:** install BlueMap from Modrinth (checked against its SHA-512) and open the 3D map in your browser.

### Content
- **Add by link:** paste a Modrinth, Hangar, SpigotMC or GitHub link, a Modrinth name, or a direct .jar URL.
  - PackCheck picks the build for the server's loader and version.
  - It checks the hash when the source publishes one, and confirms the file is a real plugin or mod jar.
- **Update all and revert:**
  - Modrinth finds newer builds of installed jars by their hash.
  - Update one at a time or all at once. The previous jar is kept, so one click puts it back.
- **mclo.gs:** share a crash report from the crash banner. PackCheck asks for confirmation first, because the report becomes public. You get the link and mclo.gs's automatic problem and solution list.

### Insights tab
- **Activity timeline:** chat, joins, leaves, deaths, advancements, player commands and server starts/stops from the last two weeks of logs, with a filter and search.
- **Scoreboard:** hours played, deaths, mob and player kills, diamonds mined, distance walked and jumps per player, read from the game's own statistics.
- **Storage:** total size, the biggest folders and files, and a safe clean-up of old logs, crash reports and caches. Worlds, configs and the current log are never touched.

### Create wizard
- **Mods first:** list the Modrinth mods you want. PackCheck finds the newest Minecraft version and loader they all support, sets up the server with it, and installs the mods.

### Also
- Server tabs wrap onto a second row when they don't fit.
