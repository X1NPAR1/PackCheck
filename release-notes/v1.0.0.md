First public release.

- Create Paper and Vanilla servers from official sources with checksum-verified downloads and Temurin Java setup
- Live console with command history and log filter, memory/CPU readout, server.properties editor, plugin manager, zip backups
- Static pack validation: structure, server.properties, corrupt JARs, duplicates, missing dependencies, api-version and Java checks
- Optional isolated startup test (temporary copy, loopback only, Job Object limits)
- JSON and HTML reports, run history with diff, pre-flight checks before plugin changes
- Headless `packcheck` CLI with CI-friendly exit codes
- English, Turkish, German, French and Russian UI; dark and light themes
- Update notifications from GitHub releases, with optional automatic updates
