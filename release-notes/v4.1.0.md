## PackCheck 4.1.0

Insights you can dig into, and plugin updates from every source.

### Insights tab
- **Scoreboard:**
  - Pick which world's statistics to read (the main `world` comes first).
  - New columns: hours since last death, items used and fish caught.
  - Sort by any column, highest or lowest first.
  - Vanilla has no "blocks placed" counter. Placing a block counts as using its item, so "items used" covers blocks, tools and food.
- **Activity timeline:**
  - Choose the time range: the last 24 hours, 7, 14, 30 or 90 days, or every log on disk.
  - Results come 500 at a time, with previous and next page buttons.
  - **Export CSV** saves every row that matches the filter, from all pages. Cells that look like spreadsheet formulas are neutralised.
  - Starts, stops, force stops and backups done in PackCheck now appear with the Windows user who did them. They are kept in `.packcheck/actions.log` in the server folder.

### Content
- **Updates from the source:**
  - Plugins added by a Hangar, SpigotMC or GitHub link, and Hangar plugins installed from the Plugins page, remember where they came from.
  - **Check for updates** asks that source when Modrinth has no newer build. It compares the version, or the SHA-256 when the version is unknown.
  - The update list shows each update's source.
- **Safer updates:** a downloaded update is checked against SHA-256 as well as SHA-512, and must be a real plugin or mod jar.
- **Check keeps going:** one source being down or timing out no longer stops the check for the other plugins.

### Fixes
- The UI tests look for controls that UI Automation can actually see, so CI is green again.
