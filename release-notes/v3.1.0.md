PackCheck now installs with a setup (EXE or MSI). If you are on 1.x, the app updates itself to this version once and then uses installer-based updates from here on.

### New
- **Installers**: per-user EXE and MSI, no administrator rights needed; updates install silently.
- **18 platforms**: Paper, Purpur, Folia, Leaf, Leaves, Spigot and CraftBukkit (built with BuildTools), Vanilla, Fabric, Quilt, Forge, NeoForge, SpongeVanilla, Mohist, Youer, Arclight, and the proxies Velocity and BungeeCord. Only versions with a real download are listed.
- **Automatic Java**: the right Temurin runtime (and a JDK for BuildTools) is installed before a server needs it.
- **Live dashboard**: ring gauges for TPS, CPU, RAM and ping with five health levels; players, uptime, disk and world size.
- **New console**: filters with counters, search, timestamps, copy and save, history, Tab completion, quick actions, player list, crash banner.
- **Files tab and code editor**: drag-and-drop upload, multi-select, copy/cut/paste, zip/unzip, Recycle Bin delete, editor with line numbers, highlighting and a syntax check before saving.
- **server.properties editor** with every setting explained.
- **Plugins and Mods pages**: browse Modrinth, Hangar and CurseForge page by page; incompatible items explain why they cannot be installed; modpacks supported.
- **Proxy page**: connect Velocity or BungeeCord to backend servers, with forwarding secret and safe backend settings written for you.
- **Online page**: open a server to the internet (firewall + UPnP), copy the address, records for your own domain, DuckDNS; close it again any time.
- **AI assistant**: pick a provider (Anthropic, OpenAI, Gemini, OpenRouter, Ollama, LM Studio) and one of its models. It reads the console, files and validation results, and can edit configs, translate plugin messages, send commands or create servers - every change waits for your approval.
- **Mod validation**: Fabric, Quilt, Forge and NeoForge metadata, missing dependencies, wrong Minecraft versions, client-only mods, duplicates.
- System tray, start with Windows, file type icons, input hints.
