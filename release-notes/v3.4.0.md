## PackCheck 3.4.0

### New
- **Modpack install.** The create wizard has a Modpack source:
  - search Modrinth modpacks or pick a .mrpack file;
  - CurseForge modpack zips work when a CurseForge key is set.
  - The server gets the Minecraft version and loader version the pack asks for. The download falls back to the latest loader, with a warning, if that exact version does not exist.
  - Files are downloaded 4 at a time and checked against their SHA-512 (Modrinth) or SHA-1 (CurseForge) hash, and only from the hosts each format allows.
  - Overrides are copied with path and size checks.
- **Clone and templates.**
  - "Clone" copies a server with or without its worlds into a new folder with a free port; logs, caches and backups are left out.
  - "Save as template" stores the server without worlds; the wizard creates new servers from templates.
- **playit.gg tunnel.** The Online page can run the official playit agent:
  - It is downloaded from GitHub and checked against the published SHA-256, then runs as its own private instance, so a playit service you already installed is not touched.
  - Link your account with the claim link, add a Minecraft Java tunnel and share the address. No port forwarding needed, and it works behind CGNAT.
- **Export / import settings.** One file with settings, the server list, automations, Discord settings and optionally assistant chats.
  - Secrets are left out by default.
  - Import shows a preview, lets you point missing server folders to new ones, and never overwrites silently.
  - Imported Java paths must point to java.exe or javaw.exe.

### Improvements
- **Assistant cost.**
  - Anthropic prompt caching is on.
  - Old, long tool results are shortened after they were sent once, so long jobs stay inside the context window.
  - The header shows cached tokens.
- **Console performance.**
  - Lines are added in batches every 100 ms, and old lines are removed in chunks.
  - In a test with about 6,000 lines per second:
    - CPU use fell from 122% to 45%;
    - memory fell from 489 MB to 331 MB;
    - switching tabs took 6 ms instead of 51 ms.
- **Updates.**
  - Interrupted downloads resume, and network errors and server errors are retried.
  - A "What's new" window shows the release notes once after an update.
  - A pending update continues when the window is hidden to the tray.

### Project
- Pull requests are now checked automatically: build and unit tests, UI tests, formatting, vulnerable package scan, CodeQL, dependency review and CodeRabbit reviews. Dependabot keeps packages up to date.
- Test packages updated (Microsoft.NET.Test.Sdk 18, xunit runner 4, coverlet 10).
