### New
- **More resources**: memory up to 256 GB and up to 64 CPU cores, in the create wizard and on the server page. Choosing more than the PC has shows a warning.
- **Automation triggers**: "When a server starts, stops or crashes" – watch this server or any other one and start, stop, restart, back up, run a command, send a chat message or notify you, after an optional delay (for example start the lobby 10 s after the proxy). "When players reach a number" does something once when the count is reached.
- New screenshots and animations in the README and on the website, taken from this version.

### Fixed
- Console commands with Turkish and other non-English letters arrive correctly (verified on a real server with a clean UTF-8 test).
