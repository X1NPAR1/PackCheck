PackCheck 3.2.0 – Minecraft server manager for Windows. This release adds the tools you need once a server is running for real: performance history, player management, crash diagnosis, safer backups, Discord notifications and a guided version upgrade.

### New
- **Performance tab**: one sample per minute kept for 7 days. Charts for TPS, tick time (MSPT), CPU, RAM and players over the last hour, 24 hours or 7 days, with a summary and ranked advice (view and simulation distance, entity activation range, memory, GC flags, "Can't keep up" warnings). Run a 30-second spark profile and open the report (spark is built into Paper 1.21+).
- **Players tab**: everyone who ever joined, with last seen, play time, IP addresses and accounts that share an IP. Whitelist, op, ban, unban and kick, whether the server is running or not.
- **Crash diagnosis**: the crash banner now names the cause – EULA, port in use, out of memory, wrong Java, missing dependency, incompatible mod, mixin failure, plugin error, broken config file (with the line number) or damaged world – and offers a one-click fix.
- **Version upgrade wizard**: choose a newer Minecraft version; PackCheck checks every plugin and mod, finds newer builds on Modrinth (verified by SHA-512), takes a pinned full backup, installs the right Java and the new server, test-starts it and rolls back with one click if the test fails.
- **Backups**: full, worlds-only or settings-only backups with a note; pin backups so they are never deleted; keep the newest N plus one per day and one per week; copy every backup to a second folder (OneDrive, Google Drive, NAS); restore everything or a single world, with a safety backup first.
- **Discord notifications** per server through a webhook: started, stopped, crashed (with the diagnosis), players, lag, backups and automation actions, an optional @here/role mention, a "Send test" button and a "post to Discord" automation action.
- **Server icon and MOTD**: turn any image into the 64×64 server icon and edit the two-line MOTD with color and style buttons and a live preview of the server list.
- **More settings**: the Properties tab now also edits the main performance settings of `bukkit.yml`, `spigot.yml` and Paper's config files, explained in five languages, keeping comments and layout, with a "changed from default" filter.

### Fixed
- Crashes that end with exit code 0 (Paper saves a crash report and shuts down cleanly) are now shown as crashes, so the crash banner and "restart after a crash" work. A forced stop by you is no longer counted as a crash.
- Backups of a running server no longer fail on files the server keeps open; the world is flushed first and saving is turned back on afterwards.
- Dates and numbers follow the app language (for example 29.10.2026 18:12 in Turkish).
- Tick time is read correctly when Java prints decimal commas.
- A MOTD written by the server in UTF-8 is read without broken characters.
