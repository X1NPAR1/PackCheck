PackCheck 3.2.1 – fixes for the dark theme, resource limits and CurseForge.

### Fixed
- **Dark theme**: profile and platform cards in the create wizard, the settings sidebar, the console's player list and other lists showed black text on a dark background. Every list now follows the theme colors.
- **Resources**: the RAM slider stops at the memory this PC really has and the CPU slider at its logical cores (up to 256 GB and 64 cores on machines that have them), in the create wizard, on the server page and for servers created by the assistant.
- **CurseForge key**: saved as soon as you type or paste it (no Enter needed); spaces, quotes and line breaks from copying are removed. A new **Check key** button asks CurseForge and says whether the key works. When CurseForge refuses a key, the Mods page says "API key rejected" instead of a bare "HTTP 403".
- **Online**: the English router guide no longer mentions Turkish internet providers; every language gives its own examples.
