# Minecraft name and brand

Notes from Mojang's Usage Guidelines and the Minecraft EULA that shape how PackCheck presents itself.

- **Name**: the product is not called "Minecraft …"; "Minecraft" only appears descriptively ("Minecraft server studio").
- **Logo**: PackCheck uses its own cube-and-check mark, not the Minecraft logo, grass block artwork or Mojang fonts.
- **Disclaimer**: the About page and README say that PackCheck is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft.
- **EULA**: PackCheck never accepts the Minecraft EULA for the user. The server creation dialog writes `eula=true` only after the user ticks the EULA box; when the assistant creates servers, the approval card the user must confirm is that consent.
- **No redistribution**: server jars are downloaded from their official sources at the user's request; PackCheck does not host or bundle them.
- **Free**: PackCheck is free and open source; it does not sell anything related to the game.
