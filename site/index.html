Minecraft server FAQ

How do I make a Minecraft server on Windows?
Install PackCheck, click New server, choose a profile such as Survival with friends, accept the Minecraft EULA and press Create server. PackCheck downloads the server, installs Java and starts it.
How can my friends join my Minecraft server?
On the same Wi-Fi they use the local address. Over the internet press Open to the internet; if your router does not forward the port automatically, follow the guide on the Online page and confirm with Test from outside.
Paper, Fabric or Forge – which should I choose?
Paper for plugins, Fabric or NeoForge for mods, Mohist or Arclight for both, and Velocity to link several servers. The create wizard explains each one.
Why does my plugin or mod not load?
Run Validate. It lists missing dependencies, Minecraft version mismatches, duplicates and corrupt files, each with the fix.
What do I need?
Windows 10 or 11 (64-bit) and about 2 GB of free memory for a small server, 6–8 GB for modpacks. Java is installed for you.
Is PackCheck free?
Yes. PackCheck is open source under the MIT license, needs no account and sends no telemetry.
