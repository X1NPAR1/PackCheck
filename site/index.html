From empty folder to friends online

The five things you do with a home server, in the order you do them.

  1. Create it

    Start from a profile – survival with friends, modded, creative, minigames, hardcore or a low-end PC – then adjust what you like.

    • RAM slider from 1 to 32 GB, with a warning when Windows would run short
    • Limit CPU cores so your games stay smooth
    • Game mode, difficulty, players, view distance, whitelist and MOTD
    • A free port is picked for you; the right Java is installed automatically

  2. Run it

    A dashboard that tells you at a glance whether the server is healthy.

    • TPS, CPU, RAM and ping gauges with history
    • Console with search, clickable player names and crash detection
    • Files tab with a code editor that checks YAML and JSON before saving
    • Backups, restart, and a tray menu that keeps servers running when the window is closed

  3. Add plugins and mods

    Browse Modrinth, Hangar and CurseForge without searching first, sorted and filtered by category.

    • Anything that does not fit your server's version or loader says why
    • Project details with the full description
    • An Update button when a newer compatible file exists
    • Modrinth modpacks install file by file with hash checks

  4. Invite your friends

    Open the server to the internet with one button, and get a straight answer when the router is in the way.

    • Windows firewall rule and UPnP router forwarding
    • A step-by-step forwarding guide with the exact values for your router
    • Test from outside: see whether friends can really reach you
    • Your own domain records or a free DuckDNS name

  5. Check before you update

    Validate the server before adding or updating plugins, and again whenever something feels off.

    • Missing dependencies, wrong Minecraft versions, duplicates, corrupt jars
    • Findings grouped by severity, category or file, each with evidence and a fix
    • Run history with what changed since last time

Broken packs, caught before the server starts

PackCheck reads every jar and config without running any plugin code, then explains what will go wrong. "Failed" and "could not check" are always reported separately, so a passing result means something.

PC040Missing dependencyEconomyShop needs ProtocolLib, which is not installed. It will not enable.
PC030Duplicate pluginHomes is installed twice; the server loads only one of them.
PC020Corrupt jarBroken.jar is not a readable archive. Download it again.
PC050Built for a newer versionA plugin declares api-version 1.21 on a 1.20.4 server.
PC066Client-only modA mod marked client-only usually crashes a dedicated server.
packcheck validate ./server --mc-version 1.21.1
Result: FAIL  (pass 12, warn 1, fail 3)
exit code 1

The same engine runs as a command-line tool, so you can check a server pack in GitHub Actions or any CI.

Questions

How do I make a Minecraft server on Windows?
Install PackCheck, click New server, choose a profile such as Survival with friends, accept the Minecraft EULA and press Create server. PackCheck downloads the server, installs Java and starts it.
How can my friends join?
On the same Wi-Fi they use the local address. Over the internet press Open to the internet; if your router does not allow automatic forwarding, follow the guide on the Online page and confirm with Test from outside.
Paper, Fabric or Forge – which one?
Paper for plugins, Fabric or NeoForge for mods, Mohist or Arclight for both, and Velocity to link several servers. The create wizard explains each platform.
Why does my plugin or mod not load?
Run Validate. It lists missing dependencies, Minecraft version mismatches, duplicates and corrupt files, each with the fix.
Is it really free?
Yes. PackCheck is open source under the MIT license, needs no account and sends no telemetry.
