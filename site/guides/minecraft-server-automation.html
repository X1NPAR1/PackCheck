Minecraft Server Automation: Restarts, Backups, Crash Recovery

A home server is much nicer when it looks after itself. PackCheck's Automation tab runs rules for each server while the app sits in the tray.

Step by step

  1. Open the Automation tab. Select the server and open Automation.
  2. Add the recommended setup. One click adds: start when PackCheck opens, restart after a crash, back up at 03:30 and restart at 04:00.
  3. Adjust the rules. Change times and days, the countdown players see, or add commands, announcements, low TPS or memory warnings, or stop-when-empty.
  4. Chain servers. Use When a server starts to start the lobby 10 seconds after the proxy, or stop it when the proxy crashes.
  5. Start with Windows. Turn on Start with Windows in Settings so the server comes back after every reboot.

Questions

How do I restart a Minecraft server automatically every day?

Add a Scheduled restart rule with the time and an optional countdown; players get a chat warning before it restarts.

Can the server restart itself after a crash?

Yes, the Restart after a crash rule starts it again, with a limit per hour so a broken server does not loop forever.
